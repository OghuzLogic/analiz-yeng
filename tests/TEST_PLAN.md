# تېست پىلانى (Test Plan) — «ئانالىزلار» پىروگىراممىسى

## 1. مەقسەت ۋە ئاساسىي پرىنسىپ
بۇ تېست پىلانى **«ئانالىزلار»** پىروگىراممىسىنىڭ يادرولۇق سودا لوگىكىسى، 8 مەركىزىي گېئوسىياسىي تېما سۈزگۈچى، ئاتالغۇ مۇستەقىللىقى، كۈندىلىك ئاپتوماتىك يېڭىلاش، RSS/Atom تېكىست پاكىزلاش، يەرلىك تەڭشەك ساقلاش، OpenRouter ئاچقۇچ باشقۇرۇش ۋە Chrome Manifest V3 مەخپىيەتلىك ئۆلچەملىرىنىڭ توغرىلىقىنى تولۇق تەكشۈرۈش ئۈچۈن تۈزۈلدى.

- **دەخلىسىزلىك پرىنسىپى (Non-invasive):** ئەسلى پىروگىرامما كودىنىڭ قۇرۇلمىسى ۋە لوگىكىسىغا ھېچقانداق زىيان يەتكۈزۈلمەيدۇ؛ بارلىق تېستلار `tests/` فولدېرى ئىچىدە مۇستەقىل ساقلىنىدۇ.
- **مۇستەقىللىق:** ھەر بىر تېست باشقا تېستقا تايانماي ئايرىم ئىجرا قىلىنىدۇ؛ `localStorage` قاتارلىق توركۆرگۈ مۇھىتلىرى `vi.stubGlobal` ئارقىلىق تەقلىد (Stub) قىلىنىدۇ.
- **تېست قورالى:** Vitest (Vite + TypeScript ئۈچۈن ئەڭ ماس كېلىدىغان زامانىۋى يۇنىت تېست قورالى).

## 3. تېست سىنارىيەلىرى تۈرلىرى

### 3.1 نورمال ئەھۋاللار (Happy Paths)
1. **8 گېئوسىياسىي تېما تونۇلۇشى:** ئەرەبچە، ئىنگلىزچە، تۈركچە ۋە ئۇيغۇرچە ماقالىلەردىن 4 چوڭ بوغۇز، روسىيە-ئۇكرائىنا، ئوتتۇرا شەرق، خىتاي ۋەزىيىتى، ئامېرىكا-ئىران، جەنۇبىي دېڭىز، ئوتتۇرا ئاسىيا ۋە شەرقىي تۈركىستان تېمىلىرىنى توغرا پەرقلەندۈرۈش.
2. **ئاتالغۇ مۇستەقىللىقى:** چەكلەنگەن مۇستەملىكىچى سۆزلەرنىڭ تولۇق ھالدا «شەرقىي تۈركىستان»، «خىتاي» ۋە «خىتاي تىلى» قىلىپ ئالماشتۇرۇلۇشى.
3. **ۋاقىت ۋە كۈندىلىك يېڭىلاش:** ئېنىق ئۇيغۇرچە چېسلا-سائەت فورماتى (`YYYY-يىل M-ئاينىڭ D-كۈنى، HH:MM`)، «بۈگۈن / تۈنۈگۈن» بەلگىسى ۋە يېڭى كۈنگە ئۆتكەندە ئاپتوماتىك يېڭىلاش شەرتىنىڭ توغرا ئىشلىشى.
4. **RSS/Atom پاكىزلاش:** CDATA، HTML بەلگىلىرى ۋە مەخسۇس ھەرپ كودلىرىنى پاكىزلاش، Atom/RSS ئۇلانمىلىرىنى ئېلىش.
5. **تەڭشەك ۋە OpenRouter ئاچقۇچ ساقلاش:** تەڭشەكلەرنى ۋە OpenRouter ئاچقۇچىنى يەرلىكتە ساقلاش، ئوقۇش، تازىلاش ۋە Chrome MV3 بىخەتەرلىك قائىدىلىرىنى تەكشۈرۈش.
6. **تېلېگراممىغا يوللاش فورماتى:** تولۇق تەرجىمە قىلىنغان ماۋزۇ، بارلىق ئابزاسلار، يادرولۇق نۇقتىلار، مەنبەسى ۋە ئۇلانما ئادرېسىنى HTML بىخەتەرلىكى ۋە ئاتالغۇ مۇستەقىللىقى بىلەن فورماتلاش.

### 3.2 چېگرا شەرتلىرى (Edge Cases)
1. ئائىلە، تۇرمۇش ۋە تەنتەربىيە سەھىپىلىرى (`/family/`, `/sport/`, `Premier League`, `شريك بلا طموح`) نى قەتئىي رەت قىلىش.
2. قۇرۇق تېكىست (`""`)، قۇرۇق بوشلۇق (`"   "`) ۋە پەقەت بەلگىلەنگەن تار تېما تىزىملىكى بىلەن سۈزۈش.
3. كۆپ تېما بىرلا ۋاقىتتا ئۇچرىغاندا ئالدىنلىق تەرتىپىنىڭ (مەسىلەن: `east-turkistan` نىڭ `china-affairs` دىن ئۈستۈن تۇرۇشى) توغرا ئىشلىشى.
4. چەكتىن ئاشقان Unicode رەقەم كودلىرى (`&#99999999;`) دا چۈشۈپ كەتمەسلىك.
5. تېلېگرامما 4096 ھەرپ چەكلىمىسىدىن ئېشىپ كەتكەن ئۇزۇن تولۇق تەرجىمىلەرنى ئابزاس بويىچە پاكىز پارچىلاش.

### 3.3 خاتالىق ۋە مۇستەسنا ئەھۋاللار (Error / Exception Cases)
1. ناتوغرا ۋاقىت تېكىستى (`invalid-date-string`) ۋە ناتوغرا تور بەت ئادرېسى (`not-a-valid-url`) بېرىلگەندە خاتالىق چىقارماي بىخەتەر قىممەت قايتۇرۇش.
2. `localStorage` دا بۇزۇلغان JSON (`{invalid-json`) ياكى مەنپىي سائەت ئارىلىقى (`-10`)، قۇرۇق تېما تىزىملىكى ساقلانغاندا سۈكۈتتىكى بىخەتەر قىممەتلەرگە قايتىش.
3. Chrome MV3 قېلىپىدا `<all_urls>` ۋە خىتاي تور دائىرىلىرىنىڭ قەتئىي بولماسلىقىنى كاپالەتلەندۈرۈش.
4. HTML مەخسۇس بەلگىلىرى (`&`, `<`, `>`) تېلېگرامما HTML قۇرۇلمىسىنى بۇزماسلىقى ئۈچۈن بىخەتەر قوغدىلىشى.
